### greetings.exe

Aplicação web interativa que apresenta frases aleatórias de humor, motivação e insights relacionados ao universo do desenvolvimento de software.

### Funcionalidades

- Geração aleatória de frases por categoria.
- Exibição de GIFs relacionados às mensagens.
- Compartilhamento de frases e link do projeto.
- Cópia da frase e do link para a área de transferência.
- Interface responsiva.

### Tecnologias

- HTML5
- CSS3
- JavaScript

### Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.

### Estrutura do projeto

- `index.html`: estrutura da aplicação.
- `style.css`: estilos e responsividade.
- `messages.js`: mensagens e categorias.
- `gifs.js`: URLs dos GIFs.
- `script.js`: lógica e interações.

### Objetivo

Criar uma experiência simples e descontraída para compartilhar humor, motivação e reflexões sobre o cotidiano de pessoas desenvolvedoras.
